size_t ast::TimeInterval::discretizedCount ( double step) const
inline

计算离散化采样点数量

返回 discretize(step) 所生成的采样点数（含首尾端点）。当 step > 0.0 且区间非空（!isEmpty()）时为 ceil(duration()/step) + 1， 点区间（start == stop）返回 1，否则返回 0（无有效采样点）。该数量不依赖于基准 epoch。

参数
step离散化步长（秒）
返回
采样点数

◆ toInterval()

Interval ast::TimeInterval::toInterval ( const TimePoint & epoch) const
inline

将绝对时间区间转换为相对于给定基准历元的相对时间区间

以 epoch 为相对时间的零点，将绝对区间折算为基于 epoch 的秒偏移量， 即 Interval{getStart() - epoch, getStop() - epoch}。

参数
epoch时间区间的基准时间点（相对时间区间的零点）
返回
相对时间区间
注解
与 setBounds(epoch, interval) 互为逆操作；对同一 epoch 二者可往返复原。
转换保持区间方向：若 start() <= stop()，则返回区间的 start_ <= stop_。 无限时间区间（±∞）映射为 Interval{∓∞}，保持无限语义；零时间区间映射为 零长度相对区间（start_ == stop_）。Interval 的聚合类型不受影响。
