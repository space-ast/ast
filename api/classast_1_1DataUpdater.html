详细描述

动态数据更新器

管理动态数据文件（EOP、空间天气等）的在线更新。 负责下载、校验、备份和替换数据文件。

使用示例：

DataUpdater updater;
auto files = updater.refreshFileList();
for (auto& f : files) {
if (f.isOutdated) {
updater.updateFile(f);
}
}
