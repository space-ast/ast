详细描述

动态库加载类

封装动态库的加载、符号解析和卸载，提供 RAII 生命周期管理。

使用示例：

Library lib("myLib");
if (lib.load() != eNoError) {
return;
}
auto func = (MyFunc)lib.resolve("myFunction");
if (func) {
func();
}
lib.unload();
