338/*
339 IAU 1994 Resolution C7 春分点补正项控制宏（仅影响 TEME）：
340
341 默认行为：采用IAU 1994 Resolution C7 春分点补正项公式（不定义宏 AST_TEME_NO_IAU1994_C7）：
342 TEME 分点差使用完整公式：ee = dpsi*cos(eps) + eqecorr(C7补正项)
343 与 SOFA iauEqeq94 、Orekit TEMEProvider 行为一致，精度更高。
344
345 如需使用不含 C7 补正项的经典公式(老公式)：
346 ee = dpsi*cos(eps + deps)
347 请在编译选项中定义 AST_TEME_NO_IAU1994_C7 宏。
348 此选项仅影响 TOD↔TEME 变换，不影响 TOD↔GTOD（该变换始终包含完整补正）。
349
350 @see IAU 1994 Resolution C7, SOFA iauEqeq94
351*/
