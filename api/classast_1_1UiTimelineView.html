时间轴视图控件

布局：

  • 底部时间轴视口：顶端为小时刻度轴，刻度线正下方为彩色区间条， 左侧固定一列显示当前时刻（格式 "07 Sep 2026 04:00:00.000"）。
  • 通过 setTimeSpan / setCurrentTime / setBars 填充数据。
