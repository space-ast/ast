详细描述

大地坐标根数

位置与速度均在天体固连系下以大地坐标及其变化率描述: lon = atan2(y, x) [rad] 大地经度(天体固连系), 自本初子午线向东为正 lat [rad] 大地纬度, 椭球法线与赤道面的夹角, 范围[-π/2, π/2] alt [m] 高度, 在参考椭球之上为正, 沿椭球法线量 lonRate [rad/s] 大地经度变化率 latRate [rad/s] 大地纬度变化率 altRate [m/s] 高度变化率

注解
与 MixedSphericalElem 的关键区别在于速度也完全在固连系下定义: vel = (N+alt)cos(lat)·lonRate·e + (M+alt)·latRate·n + altRate·u , 其中 e、n、u 为当地东、北、天单位矢量, N、M 为卯酉圈与子午圈曲率半径。 因此 vel 为零(如地球同步轨道)时三个变化率亦为零, 与惯性速度无关。 需要参考形状(椭球, 见 BodyShape)以及参考系与固连系之间的运动学变换(见 KinematicTransform)。 极点(lat=±π/2)处经度率奇异, 正向转换取lonRate=0(约定), 与 SphericalElem 的赤经一致。 参见 aCartToGeodetic 和 aGeodeticToCart
