详细描述

Markdown SAX → ANSI 终端转义序列渲染器

实现 MarkdownSax 接口，将 SAX 事件转换为带 ANSI 颜色的终端输出。 与 MarkdownParser 配合使用：

MarkdownANSI renderer;
MarkdownParser parser(renderer);
parser.feed(markdownText);
parser.finish();
std::string result = renderer.output();
