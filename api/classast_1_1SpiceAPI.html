详细描述

Spice API

处理CSPICE库的动态加载、卸载、函数调用等 这里只对CSPICE库进行简单的包装：

  • 在保证接口不变的情况下，确保线程安全
  • 针对文件加载增加了引用计数机制
  • 处理了文件路径的编码问题
    警告
    注意CSPICE库的默认长度单位是**千米**
