详细描述

恒定空间天气数据提供者

SpaceWeatherProvider 的具体实现，所有查询方法返回用户预设的常数值。 默认值代表中等太阳活动水平下的典型空间天气条件。

使用示例：

// 使用默认值
ConstantSpaceWeather sw;
double ap = sw.getApDaily(tp); // 返回 15.0
// 自定义值
ConstantSpaceWeather sw(150.0, 150.0, 15.0, 3.0);
