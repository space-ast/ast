详细描述

时间点列表

时间点列表以相对秒数 + 参考历元的形式存储时间序列。

存储模型：

  • seconds_ : std::vector<double> — 相对于 epoch_ 的秒偏移量
  • epoch_ : TimePoint — 参考历元

不假设列表有序。使用方式与 std::vector<double> 一致， 同时提供时间语义方法将偏移量转换为绝对 TimePoint。

注解
列表可以无序。如需二分查找等操作，请先确保排序。

警告
