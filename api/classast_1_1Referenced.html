◆ destruct()

void ast::Referenced::destruct ( )
inline

析构对象，仅当强引用计数为0时才会被调用

析构对象时，会先将弱引用计数减1，若弱引用计数为0，则会调用析构函数

警告
对于栈上的对象，不要调用该函数，避免对栈内存调用 delete 导致崩溃
