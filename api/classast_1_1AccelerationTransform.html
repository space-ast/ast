详细描述

加速度(二阶运动学)坐标系变换

在运动学坐标系变换的基础上，增加了坐标系旋转的角加速度和平移的加速度， 因此可以变换由位置、速度和加速度组成的二阶状态量，而不只是位置和速度。

注解
参考系约定与 KinematicTransform / AccelerationRotation 一致： 平移 t、平移速度 V、平移加速度 A 均取源坐标系分量； 角速度 ω、角加速度 α 表示本坐标系相对源坐标系(父坐标系)的量，其分量在源坐标系下分解， 且 α 为该分量的坐标时间导数。 其中 A 约定为平移 t 的坐标二阶导数。
警告
平动加速度为零、旋转角加速度为零的两个变换组合之后，其加速度一般并不为零： A = 2ω₁×(M₁ᵀV₂) + ω₁×(ω₁×τ)，α = ω₁×(M₁ᵀω₂)（τ = M₁ᵀt₂）。 即内层坐标系一旦相对转动，外层的匀速平移在源坐标系下就表现为圆周运动。

变换位置、速度和加速度

设 ρ = p − t 为点相对目标坐标系原点的位置，ρ̇、ρ̈ 分别为其在源坐标系下的 坐标导数和坐标二阶导数，则 positionOut = M ρ velocityOut = M ( ρ̇ − ω×ρ ) accelerationOut = M ( ρ̈ − 2ω×ρ̇ − ω̇×ρ + ω×(ω×ρ) )

参数
position位置（源坐标系分量）
velocity速度（源坐标系分量）
acceleration加速度（源坐标系分量）
positionOut变换后的位置
velocityOut变换后的速度
accelerationOut变换后的加速度

先进行坐标系平移（含速度和加速度），再进行加速度旋转。
