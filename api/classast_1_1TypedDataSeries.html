template<typename T>
class ast::TypedDataSeries< T >

DataSeries 的类型化子类

模板参数
T元素类型（double, int, std::string, TimePoint）

继承自 DataSeries，不添加任何数据成员，仅提供类型安全的成员函数。 可通过 DataSeries::as<T>() 或 static_cast 从基类引用转换。 所有方法均为 inline，零运行时开销。
