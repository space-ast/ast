详细描述

主/低高度大气密度模型的混合过渡模型

在过渡高度附近，将"主大气模型"（高高度模型）与"低高度模型"按高度线性混合：

  • 高度 ≤ blendAltitude - blendRange/2：全部使用低高度模型；
  • 高度 ≥ blendAltitude + blendRange/2：全部使用主模型；
  • 过渡带内：对两者按高度线性加权（低高度偏重低高度模型，高高度偏重主模型）。
