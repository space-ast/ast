详细描述

运动学坐标系旋转

在静态坐标系旋转的基础上，增加了坐标系旋转的角速度信息

注解
角速度的参考系约定：angvel 表示本坐标系相对源坐标系(父坐标系)的角速度， 且其分量在源坐标系(父坐标系)下分解。 例如： aAxesTransform(source, target, tp, kr) 给出的 kr.rotationRate() 是 target 相对 source 的角速度在 source 下的分量。
