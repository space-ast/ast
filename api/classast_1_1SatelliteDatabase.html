详细描述

卫星数据库

继承自 Database，可解析 CelesTrak SATCAT Legacy Text Format 格式的卫星目录文件。

  • 每行表示一颗卫星，固定 132 字符列宽
  • 类别（mission）从卫星名称自动派生（取名称首词）
