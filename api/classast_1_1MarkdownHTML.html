详细描述

Markdown SAX → HTML 渲染器

实现 MarkdownSax 接口，将 SAX 事件转换为 HTML 标签输出。 与 MarkdownParser 配合使用：

MarkdownHTML renderer;
MarkdownParser parser(renderer);
parser.feed(markdownText);
parser.finish();
std::string html = renderer.output();
