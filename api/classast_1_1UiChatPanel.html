聊天面板

聊天功能的主面板，管理对话的完整生命周期：

  1. 用户输入 → 追加用户消息气泡
  2. 启动 UiChatWorker 后台线程调用 LLM
  3. 通过 UiChatEventHandler 实时更新助手消息气泡
  4. 工具调用时插入 UiToolCallCard
  5. 对话完成后恢复输入
