变类型向量容器

该类可以存储不同数据类型的向量，无需在编译时指定具体类型， 但一次只能存储一种特定类型的数据。

类型元数据（TypeOps*、type_info*、elementSize）嵌入在分配块头部， data_ 指针永远指向第一个元素。data_ == nullptr 表示未设置类型。

使用方式：

VariantVector v;
v.resize<double>(100); // 首次调用确定类型为 double
v[0] = 3.14; // 类型安全访问
assert(v.elementType() == typeid(double));
