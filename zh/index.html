SpaceAST

面向航天仿真的现代 C++ 算法库

快速上手模块参考API 手册下载

高精度轨道传播

二体、J2/J4 解析传播与 HPOP 数值传播，支持多种摄动力模型。

完整的坐标与时间体系

J2000/ECEF 变换链、儒略日与 UTC/TAI/TT 转换、JPL DE 与 SPK 星历读取。

姿态与数学基础

四元数、欧拉角、方向余弦矩阵，以及线性代数、ODE 积分与插值。

模块化共享库

core、math、util 等独立模块按需链接，依赖关系清晰。

跨平台构建

支持 Windows 与 Linux，兼容 C++11，可使用 xmake 或 CMake 集成。

Python 绑定

通过 SWIG 暴露核心接口，便于脚本化验证与二次开发。
